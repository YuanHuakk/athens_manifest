# athens · Project Infinity X 构建清单

Redmi K100 Pro（Athens）的 Android 17 构建清单、适配补丁和构建工具。PixelOS、Evolution X 与 Infinity X 共用设备树的 [`android-17` 分支](https://github.com/YuanHuakk/android_device_xiaomi_athens/tree/android-17)。

`default.xml` 补充 Infinity X 官方清单，`patches/series.json` 定义补丁顺序。`manifests/` 保留 PixelOS r12 的历史清单。
